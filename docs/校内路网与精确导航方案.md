# 校内自建路网 · 更精确导航方案

> 目标：做出比市面通用地图更精确的校园导航 —— 精确到楼栋入口、连廊、小路，甚至知道哪条路不通。

## 一、为什么需要自建路网？

现在的导航用的是「腾讯地图公共路网」：
- 优点是开箱即用、覆盖全
- 缺点是**校内的细节它不知道**：楼间小路、连廊、禁行区、施工路段、哪栋楼哪个门进……

自建路网 = 我们把**校内每一条能走的路**自己画出来，存成数据。
导航时就在我们自己的路网上算路线，精度完全可控。

## 二、路网是什么？

路网 = **节点 + 边**（就是图论里的"图"）：

- **节点**：路口、转弯点、楼栋门口。每个节点有经纬度。
- **边**：两个节点之间的一段可通行道路。每条边可以标注：
  - 能否步行 / 能否骑行
  - 是否单行（骑行常用）
  - 名称（如"东祥路"）

```
节点：N1(34.0339,108.7698) 东大门
      N2(34.0320,108.7680) 图书馆路口
边：  N1→N2  可步行、可骑行
      N2→N3  可步行、可骑行
```

## 三、制作路网的三步

### 第 1 步：采集坐标（最花时间，但一次做好永久受益）

**推荐工具：腾讯地图坐标拾取器**
1. 打开 https://lbs.qq.com/getPoint/ （腾讯坐标拾取器）
2. 缩放到校园，逐个点击：校门口、每个路口、转弯点、楼栋入口
3. 每次点击会显示经纬度，抄下来（或用脚本批量收集）

**进阶：QGIS 画路网**
1. 装 QGIS，加载卫星影像图（可用高德/腾讯地图截图）
2. 沿道路画线，导出自定义 GeoJSON
3. 用脚本转成小程序 JSON 格式

**建议顺序**：
- 先画**主干道**（正门 → 图书馆 → 食堂 → 宿舍区 → 教学楼）
- 再补**楼间小路**和**连廊**
- 最后加**楼栋入口点**（导航到"哪个门"）

> 长安校区范围不大，主干道 + 主要小路约 **100~200 个节点、200~400 条边**，
> 认真画 2~3 天能初步跑通，之后随时补充。

### 第 2 步：整理成数据文件 `data/roadnet.js`

## 四、精确导航还能做什么（基于路网）

1. **地图匹配（吸路）**：实时定位点"吸附"到最近的路网边上
   —— 导航页里已经写好的 `navPointSeg`（点到线段最近距离）就是干这个的，直接复用！
2. **到路口提醒**：当前边走完前 20 米振动提醒"前方左转进入 xx"
3. **偏离提醒**：定位点离路网超过 20 米 → 提示"您已偏离路线"
4. **禁止通行**：施工路段、只出不进的门，都能在路网上体现
5. **骑行专用**：单行道、禁行路段在骑行模式下自动避开

## 五、和现有代码怎么衔接

- `utils/route.js` 保留腾讯 API 作为**兜底**（路网没覆盖的地方）
- 新增 `utils/roadnet.js`：路网数据 + A* 寻路 + 地图匹配
- `pages/route/route.js` 流程改为：
  1. 优先用自建路网算路线（秒出，不耗 API 配额）
  2. 路网没覆盖/没数据时，退回腾讯 API

## 六、优先级建议（从易到难）

| 阶段 | 内容 | 收益 |
| --- | --- | --- |
| 1 | 画主干道路网 + A* 寻路 | 校内路线秒出、不耗配额 |
| 2 | 楼间小路 + 楼栋入口 | 精确到门 |
| 3 | 实时导航地图匹配 | 定位吸附、到路口提醒 |
| 4 | 骑行路网（单行、禁行） | 骑行导航更准 |
| 5 | 施工/临时禁行动态标记 | 实时性 |
