# 🗺️ NPUmap · 校园地图小程序

西北工业大学（长安校区 + 友谊校区）轻量化校园地图与导航微信小程序。面向新生和在校生：找教学楼、查食堂、规划校内步行路线、管理课表，开学不迷路。

> ⚠️ 本项目为个人开发的学习/生活工具，非学校官方项目。

## ✨ 功能一览

- 🏫 **双校区地图**：长安校区 / 友谊校区一键切换（毛玻璃滑动动画）
- 📍 **校园地点**：40+ 地点（教学楼、食堂、宿舍、体育馆、公交站、校车站），支持搜索、收藏、置顶、按访问频率排序
- 🚶 **校内路线规划**：小程序内画出步行路线 + 转向步骤（腾讯位置服务）
- 🚏 **常用路线收藏**：一键直达常走的路
- 📅 **我的课表**：一次添加多门课，支持步行时间估算、一键去上课
- 💬 **校园评论**：每个地点可发文字 + 图片评论
- 📸 **校园图鉴**：自动收集评论里的地点实拍图
- 🏅 **探索打卡**：逛校园攒徽章（7 枚成就）
- 🎨 **主题系统**：7 套校园主题 + 深色模式 + 隐藏主题彩蛋（搜索框输入暗号解锁）
- 📄 关于我们 / 隐私政策 / 用户协议 / 更新日志

## 🚀 本地运行

1. 下载「[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)」（免费）
2. 打开工具 → 导入项目 → 选择本目录
3. **复制 `config.example.js` 为 `config.js`**，填入你的腾讯位置服务 key
4. 开发者工具 → 详情 → 本地设置 → 勾选「不校验合法域名…」
5. 点击编译，即可在模拟器看到效果

## 🔑 需要的 key

- **腾讯位置服务**（地图 + 校内路线）：到 [lbs.qq.com](https://lbs.qq.com) 注册 → 控制台创建应用 → 添加 key
  - 产品类型勾选「WebServiceAPI」+「微信小程序」（绑定你的 AppID）
  - 开启「签名校验（SN）」会生成 SK
  - 把 key / SK 填入 `config.js`
- **微信小程序 AppID**：到 [微信公众平台](https://mp.weixin.qq.com) 注册小程序后获得

## 📌 温馨提示

- 地点坐标来自地图拾取 + 公开资料整理，**建议开学后在校园里实测核对**（见 `data/地点核对清单.md`）
- 校内路线依赖腾讯地图路网，日常够用；精确到楼栋入口需要自建路网（后续进阶方向）
- 评论 / 打卡 / 收藏等数据存在**手机本地**（未接入服务器）
